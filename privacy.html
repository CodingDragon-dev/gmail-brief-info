Gmailブリーフプライバシー利用条件

プライバシーポリシー

Gmailブリーフは、運用者本人のメールを整理するための個人利用プログラムです。本ポリシーは、本プログラムによるGoogleユーザーデータの取り扱いを説明します。

取得する情報と目的

利用者が認証したGmailアカウントのアドレス、メールID、差出人、件名、受信日時、本文を読み取ります。メールへの対応事項を選別し、根拠へのリンク付きブリーフを生成するために使用します。

アクセスの範囲

GoogleのOAuth認証でGmail読み取り専用権限（gmail.readonly）を要求します。この権限自体はメールボックスを読み取れる権限ですが、プログラムの検索は受信トレイ内の対象期間に限定し、迷惑メール・ゴミ箱・プロモーション・ソーシャルを除外します。1回の実行で取得する候補は2アカウント合計で最大40件です。

OpenAIへの送信

要約対象の候補メールのアドレス、差出人、件名、日時、本文、参照情報を、利用者がChatGPTアカウントでログインしたCodex CLIを通じてOpenAIへ送信します。OpenAI側の処理には、利用者の契約とデータ設定、およびOpenAIのプライバシーポリシーが適用されます。GmailのOAuthトークンやGoogleアカウントのパスワードは要約データに含めません。

保存先と保存期間

Googleの認証情報、アカウント別の前回成功日時、ブリーフを利用者のPCに保存します。認証情報の保存フォルダはWindowsのアクセス権で制限します。Codexは一時実行モードを使用し、ローカルの通常の会話履歴として保存しません。ブリーフ履歴は最新90レコードを保持します。選別されなかった候補本文は、ブリーフ履歴には保存しません。

共有と利用制限

Googleユーザーデータを広告、販売、信用判断のために利用しません。この公開サイトへメール情報を送信・掲載しません。Google APIから取得した情報の利用および他のアプリへの転送は、Google API Services User Data PolicyのLimited Use要件に従います。

アクセス取り消しと削除

Googleアカウントの「サードパーティ製アプリとサービス」からGmailブリーフのアクセスを取り消せます。PC上のWindowsタスクを停止し、privateフォルダの認証情報およびdataフォルダの保存済みブリーフを削除すれば、継続アクセスとローカル保存を終了できます。OpenAI側のデータ管理については、OpenAIの設定・ポリシーをご確認ください。

公開ページのホスティング

この説明サイトをGitHub Pagesで公開する場合、GitHubがセキュリティ目的で閲覧者のIPアドレス等を記録します。詳しくはGitHubのプライバシーに関する声明をご参照ください。このサイトには独自のアクセス解析や広告を設置していません。
